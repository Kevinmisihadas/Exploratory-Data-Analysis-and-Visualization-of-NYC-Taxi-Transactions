# Exploratory Data Analysis and Visualization of NYC Taxi Data

## Project Overview

This project focuses on performing Exploratory Data Analysis (EDA) on the NYC Taxis dataset using Python. It involves data cleaning, handling missing values, statistical exploration, and data visualization using Pandas, Matplotlib, and Seaborn.

The objective is to analyze taxi trip patterns, fare distributions, trip distances, borough-wise transactions, and payment methods through meaningful visualizations.

## Dataset

- **Dataset Name:** NYC Taxis Dataset
- **Source:** Seaborn Built-in Dataset
- **Loading Method:** `sns.load_dataset("taxis")`
- **Description:** Contains information about taxi trips in New York City, including pickup and drop-off timestamps, locations, trip distance, fare, tips, tolls, and payment methods.

### Important Features

| Feature | Description |
|---|---|
| pickup | Pickup date and time |
| dropoff | Drop-off date and time |
| pickup_borough | Pickup borough |
| pickup_zone | Pickup zone |
| distance | Trip distance |
| fare | Trip fare |
| tip | Tip amount |
| tolls | Toll charges |
| total | Total trip amount |
| payment | Payment method |

## Analysis Objectives

1. Understand the structure and characteristics of the NYC Taxis dataset.
2. Identify and handle missing values using appropriate imputation techniques.
3. Explore taxi fare patterns over time.
4. Analyze total fare across different pickup boroughs.
5. Examine the distribution of payment methods.
6. Understand trip distance and tip distributions.
7. Investigate relationships between distance, fare, tips, and total charges.
8. Identify correlations among numerical variables.
9. Compare fare distributions across different payment methods and pickup zones.

## Data Preprocessing

The following preprocessing techniques were implemented:

- Checked dataset structure using `info()` and `describe()`.
- Identified missing values using `isnull().sum()`.
- Used median imputation for numerical columns.
- Used mode imputation for categorical columns.
- Removed rows with missing values in critical columns such as pickup timestamp, fare, distance, and pickup borough.
- Converted the pickup column into datetime format.
- Sorted records based on pickup timestamp.

## Key Insights and Observations

The visualizations help explore the following patterns:

1. **Fare and Distance Relationship:** Longer taxi trips generally tend to have higher fares, indicating a positive relationship between distance and fare.

2. **Borough-wise Fare Analysis:** The bar chart allows comparison of total fare generated by different pickup boroughs.

3. **Payment Distribution:** The pie chart reveals the proportion of trips made using different payment methods, such as credit cards and cash.

4. **Trip Distance Distribution:** The histogram helps identify common trip-distance ranges and the presence of unusually long trips.

5. **Tip Distribution:** The box plot highlights differences in tip amounts across boroughs and helps identify potential outliers.

6. **Correlation Analysis:** The heatmap helps identify positive and negative relationships among numerical variables such as distance, fare, tip, tolls, and total.

7. **Payment-based Fare Comparison:** The violin plot provides insights into how fare distributions vary across payment methods.

8. **Pickup Zone Analysis:** The pair plot helps compare numerical trip characteristics across different pickup zones.

*Note: These are qualitative observations and analytical interpretations. Exact rankings, correlation coefficients, and numerical findings have not yet been recorded.*
